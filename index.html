Sloth Sure

SlothSure Project Details

Hosted by DevPost
  • HackPrinceton @ Princeton University
  • About : We were aiming to solve the problem of bad posture for developers and gamers. We used sensors straped on to the back of an individual which detected slouching and used a vibrating motor to alert them.
  • Tools : Arduino SDK, C++, Python, Javascript, CSS, HTML

Major Way

Major Way Project Details

Hosted by DevPost

  • HoyaHacks @ Georgetown University | Best Education Hack
  • About : We created a web app that provide STEM majors a outlines all the different areas of study in their major. We used graph intersection and NLP python packages.
  • Tools : Python, JavaScript, Bootstrap, Jquery, Flask and Natural Language Processing

Kindrone: 3rd Place

Kindrone Project Details

Hosted by DevPost

  • DragonHacks @ Drexel University | 3rd Place
  • About : We developed a program that used the Kinect sensors to communicate with an AR.Drone, allowing it to control the drone via the use of hand gestures.
  • Tools : KinectSDK, AR.DroneSDK, C#, VisualBasic
